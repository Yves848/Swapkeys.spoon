**Demande :** compléter la gestion fenêtres/desktops via Hammerspoon (SIP OK), ajouter un
placement style Magnet/Rectangle, une aide visuelle, et un thème yabai — le tout sur
clavier **AZERTY belge**.

**Actions :**
- **Desktops (`Yabai.spoon`)** : Spaces relatifs (prev/next + envoi & suivi), création /
  destruction, multi-écrans (focus / envoi / déplacer le Space entier), cycle de layout,
  warp directionnel, helper `_query`. Filtre des alertes de navigation bénignes
  (« could not locate … managed window »). Bascule **pavage auto ↔ manuel**
  (`layout_toggle`, ⌃⌥⌘T). Fix `toggle_float` (retrait `--grid` → fin de l'erreur
  « cannot apply grid layout to a managed window »).
- **AZERTY belge** : raccourcis Spaces/écrans re-mappés sur touches **natives** du keymap
  (`, ; =`) au lieu de `[ ] .` (touches mortes via fallback US).
- **`WindowSnap.spoon` (nouveau)** : placement Magnet/Rectangle sur **⌘⌥** (moitiés, quarts,
  tiers, plein, centré). Rend la fenêtre flottante via yabai avant de la placer. `gap=10`
  pour laisser voir l'anneau de focus.
- **Mode manuel** : yabai passé en `layout float` (yabairc + à chaud) → plus d'auto-tiling ;
  ⌘⌥ devient l'outil de rangement.
- **`CheatSheet.spoon` (nouveau)** : popup flottant **⌃⌥H** (`hs.webview` non-activant)
  listant tous les raccourcis. Fixes : ombre native → CSS, hauteur ajustée au contenu.
- **Cheat sheet PDF** : `docs/cheatsheet-hammerspoon.(html|pdf)` (Chrome headless).
- **Thème** : JankyBorders (anneau de focus bleu, 4px), opacité (inactives 90 %), ombres
  `float`, **SketchyBar** relancé (SbarLua compilé) + accent bleu aligné, barre native
  masquée (`_HIHideMenuBar`). Animations yabai en attente (permission « Enregistrement de
  l'écran »).
- **Versioning** : configs `~/.config` (yabai, borders, sketchybar) rapatriées dans
  `config/` (miroir, binaires exclus) + `README.md`.

**Fichiers :** `Yabai.spoon/`, `WindowSnap.spoon/`, `CheatSheet.spoon/`,
`docs/cheatsheet-hammerspoon.*`, `config/**`, `CLAUDE.md`, `~/.hammerspoon/init.lua`,
`~/.config/{yabai,borders,sketchybar}/`.
