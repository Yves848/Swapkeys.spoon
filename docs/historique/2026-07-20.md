## Réalisé : yabai installé, service démarré, HS en mode tiling

**Demande :** dérouler la mise en place effective de yabai.

**Actions (côté machine, faites automatiquement) :**
- `brew install asmvik/formulae/yabai` → yabai **v7.1.25** installé.
- Réglage Mission Control : `mru-spaces=false` (+ Dock relancé).
- `yabai --start-service` : après une relance, service actif (accessibilité effective,
  yabai gère 7 fenêtres, voit 4 Spaces). Config chargée : bsp, gap/padding 8px, souris
  Alt, 11 règles float (dont apps perso).
- `init.lua` : guard rendu robuste (bascule yabai seulement si le service **répond**,
  pas juste si le binaire existe) ; reload HS → **mode tiling actif**, aucune erreur.

**État :** tiling + focus/échange de fenêtres **opérationnels maintenant**. Les Spaces
(⌃⌥⌘ chiffres) nécessitent encore la *scripting addition* → 2 étapes manuelles restantes.

**Reste à faire (utilisateur) :**
1. Ajouter la ligne sudoers (`sudo visudo -f /private/etc/sudoers.d/yabai`) — hash déjà
   généré.
2. Désactiver SIP partiellement (reboot Recovery) → au redémarrage suivant, `--load-sa`
   passe et les Spaces s'activent.

**Fichiers :** `~/.hammerspoon/init.lua` (guard robuste), `~/.config/yabai/yabairc` (déjà
présent). **Commit :** ce fichier d'historique.
